# Week 2 - Feature Scaling Engine

## Machine Learning Internship Task
Week 2 assignment: Data preprocessing, normalization, and categorical scaling.

## What This App Does
A Streamlit web application that prepares dataset matrices for ML model inputs through:
- One-Hot Encoding for categorical variables
- Standard Scaler (z-score normalization)
- MinMax Scaler (0-1 normalization)
- Feature analysis and CSV download
